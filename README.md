# HR Analytics Dashboard – Power BI

## 📊 Project Overview

This project is an interactive HR Analytics Dashboard developed using Microsoft Power BI.

The dashboard provides insights into employee demographics, job satisfaction, promotion, retrenchment, overtime, job levels, and workforce information.

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Data Visualization
- Excel

## 📈 Key Features

- Total Employee Analysis
- Gender Distribution
- Promotion Analysis
- Retrenchment Analysis
- Job Satisfaction Analysis
- Overtime Analysis
- Job Level Analysis
- Distance from Office Analysis
- Employee-level Action Tracking

## 🎯 Objective

The objective of this project is to transform HR data into meaningful visual insights that can help HR teams understand workforce trends and identify employees requiring promotion or retrenchment-related attention.
